# iPhone X Forensic Investigation: Evidence and Scope

## Case Overview

This case study documents an examination of an iPhone X full-file-system forensic dataset using Cellebrite Reader.

The examination forms part of a broader mobile device forensic investigation involving iOS and Android evidence.

## Evidence Source

| Item | Description |
|---|---|
| Device | iPhone X |
| Dataset | iPhone X Full File System |
| Examination tool | Cellebrite Reader |
| Source | Provided mobile forensics lab dataset |

## Examination Scope

The iOS examination focuses on identifying and interpreting artifacts available within the supplied forensic dataset.

Areas of examination include:

- Application-related artifacts
- Device and user-activity records
- Relevant timestamps and log entries
- Correlation of artifacts within the available evidence

## Examination Limitations

The investigation is based on a provided forensic dataset rather than a newly acquired physical device.

The public portfolio will not contain the original dataset, credentials, private communications, or unredacted personal information.
