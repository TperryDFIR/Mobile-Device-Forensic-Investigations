# iOS Forensic Investigation: Supporting Screenshots

## Overview

This directory contains selected screenshots documenting the examination of an iPhone X full file system forensic report using Cellebrite Reader.

The screenshots support the findings documented in the iOS forensic investigation and are provided for educational and portfolio purposes.
