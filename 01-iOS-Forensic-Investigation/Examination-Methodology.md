# iPhone X Forensic Examination Methodology

## Examination Objective

The objective of this examination was to identify and analyze relevant artifacts within a provided iPhone X full-file-system forensic dataset.

## Evidence and Tool

| Item | Description |
|---|---|
| Evidence | iPhone X Full File System dataset |
| Examination tool | Cellebrite Reader |
| Examination type | Analysis of a provided forensic extraction |

## Examination Workflow

1. Opened the provided iPhone X forensic dataset in Cellebrite Reader.
2. Reviewed the available artifact categories and device information.
3. Examined relevant application and user-activity artifacts.
4. Reviewed timestamps and log entries associated with the available evidence.
5. Documented relevant observations using tool output and supporting screenshots.

## Timestamp Considerations

Timestamps must be interpreted with their associated time zones. Where necessary, displayed times should be checked against the source artifact before drawing conclusions about event order.

## Reporting Approach

Findings will distinguish between artifacts directly observed in the dataset and interpretations derived from those artifacts.

Screenshots included in the public portfolio will be reviewed for personal information and redacted where necessary.

## Examination Limitations

This case study examines an existing forensic extraction. It does not claim that a new physical acquisition of the iPhone X was performed.
